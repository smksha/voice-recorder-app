# Voice Recorder App

A professional voice recording mobile application built with React Native 0.81+, TypeScript, and Expo SDK 54.

## Quick Start

Navigate to the project directory and start the development server:

```bash
cd voice-recorder
npm start
```

Then follow the on-screen instructions to run on your device or emulator.

## Project Details

For complete documentation, features, and usage instructions, see the [Voice Recorder README](./voice-recorder/README.md).

## Tech Stack

- React Native 0.81.5
- Expo SDK 54.0.30
- TypeScript 5.9.2
- expo-av (audio recording/playback)
- expo-file-system (file management)
- AsyncStorage (metadata persistence)

## Features

✅ High-quality audio recording  
✅ Recording list with date, time, and duration  
✅ Audio playback functionality  
✅ Delete recordings  
✅ Local persistent storage  
✅ Modern dark-themed UI  
✅ TypeScript for type safety
